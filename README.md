# ServoDriveTrainPractice2025



This is my personal fork of the `SouthEugeneRoboticsTeam/DriveTrainPractice` repository. I set this up as a sandbox to practice servo drive train coordination and programming.

## What is this?

Right now, it's mostly just a scratchpad for me to experiment with writing the robot code entirely in Kotlin. My branch is currently 4 commits ahead of the main team branch because I'm just pushing test files, backup code, and setup scripts to see what works.

Since this is just my practice area, it's a bunch of mashed-together files and isn't guaranteed to compile or run on the actual bot yet. Don't try deploying this to hardware.

## Current Files

* **`DriveTrainPractice/`**: This is where I'm testing the experimental Kotlin code and messing around with automations for the build environment


* **`WPILib-License.md`**: Standard licensing info for the WPILib libraries.
